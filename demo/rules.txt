Diabetes Progression Challenge: Competition Rules (mock, for the Clean Room demo)

1. Data
1.1 Participants may use train.csv and test.csv from the official data bundle.
1.2 The file test_labels.csv is provided for organiser scoring only and must not be read by participant code.
1.3 External data is not permitted. Do not download additional rows, pre-trained models or other datasets from any website.

2. Environment
2.1 Submissions are evaluated offline: internet access is disabled during evaluation and code must not make network calls.
2.2 Only the provided Python environment may be used; installing packages during evaluation is not allowed.

3. Reproducibility
3.1 Winning solutions must be reproducible: fix all random seeds so that a re-run produces the same submission file.
3.2 Organisers may re-run the winning code and compare the output with the submitted file.

4. Submissions
4.1 Each team may submit up to 5 entries per day and must select 2 final entries.
4.2 Submit a CSV with columns id and pred, where pred is the predicted probability that progression is above the median.
